7. In $\triangle ABC$, $B = 30^\circ$ and $AB = 20$ cm.

Explain (a) Kelvin claims that the minimum length of $AC$ is 10 cm. Do you agree? Explain your answer.

(b) Find the range of the length of $AC$ such that two triangles can be formed.

(a) $\sin 30^\circ = \frac{AC}{20}$  
$AC = 10$ cm  
$\therefore$ Yes  

(b) $10\text{ cm} < AC < 20\text{ cm}$

**Supplementary Example 4** Level 2 (P.9.8)  
In each of the following, use the sine formula to find $B$ in $\triangle ABC$.  
(a) $A = 40^\circ$, $b = 7$ cm, $a = 5$ cm  
(b) $A = 40^\circ$, $b = 7$ cm, $a = 10$ cm  
(Give the answers correct to 3 significant figures.)  

(a) $\frac{7}{\sin B} = \frac{5}{\sin 40^\circ}$  
$B = 64.1^\circ$  
or $116^\circ$  

(b) $\frac{7}{\sin B} = \frac{10}{\sin 40^\circ}$  
$B = 26.7^\circ$

**Supplementary Example 5** Level 2 (P.9.9)  
Solve $\triangle ABC$ in each of the following.  
(a) $A = 120^\circ$, $b = 9$ cm, $a = 15$ cm  
(b) $A = 120^\circ$, $b = 9$ cm, $a = 5\sqrt{3}$ cm  
(Give the answers correct to 3 significant figures.)  

(a) $\frac{9}{\sin B} = \frac{15}{\sin 120^\circ}$  
$B = 31.3^\circ$  
$(+120^\circ + 31.3^\circ = 180^\circ)$  
$C = 28.7^\circ$  
$\frac{c}{\sin 28.7^\circ} = \frac{15}{\sin 120^\circ}$  
$c = 8.32$  

(b) $\frac{9}{\sin B} = \frac{5\sqrt{3}}{\sin 120^\circ}$  
$B = 64.2^\circ$  
$A + B = 120^\circ + 64.2^\circ$  
$= 184.2^\circ$  
$> 180^\circ$  
$\therefore$ No solution
