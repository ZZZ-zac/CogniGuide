Solve the following triangles. [Nos. 7–9]

7.  
![](https://i.imgur.com/placeholder.png)  
$88^\circ + 35^\circ + B = 180^\circ$  
$B = 57^\circ$  

$\frac{CA}{\sin 57^\circ} = \frac{31}{\sin 88^\circ}$  
$CA = 26.0\,\text{cm}$  

$\frac{CB}{\sin 35^\circ} = \frac{31}{\sin 88^\circ}$  
$CB = 17.8\,\text{cm}$  

8.  
![](https://i.imgur.com/placeholder.png)  
$22^\circ + 123^\circ + C = 180^\circ$  
$C = 35^\circ$  

$\frac{19}{\sin 35^\circ} = \frac{CA}{\sin 22^\circ}$  
$CA = 12.9\,\text{cm}$  

$\frac{CB}{\sin 123^\circ} = \frac{19}{\sin 35^\circ}$  
$CB = 27.8\,\text{cm}$  

9.  
![](https://i.imgur.com/placeholder.png)  
$B + 87^\circ + 41^\circ = 180^\circ$  
$B = 52^\circ$  

$\frac{22}{\sin 52^\circ} = \frac{BC}{\sin 41^\circ}$  
$BC = 18.3\,\text{cm}$  

$\frac{AB}{\sin 87^\circ} = \frac{22}{\sin 51^\circ}$  
$AB = 27.9\,\text{cm}$
